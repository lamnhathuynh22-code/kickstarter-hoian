# Da Nang & Hoi An — 22–27 December 2026

A standalone, responsive English itinerary page for the Singapore group.

## Publish on your current GitHub Pages website

1. In your local `kickstarter-hoian` repository, create `pages/danang-hoian-dec2026/`.
2. Copy `index.html` from this download into that directory.
3. Preview locally by opening `index.html` in Chrome, or with VS Code Live Server.
4. GitHub Desktop: commit and push to `main`.
5. Once GitHub Pages deploys, visit:
   `https://www.kickstarterhoian.com/pages/danang-hoian-dec2026/`

No CSS or JavaScript files are needed. CSS is embedded directly in HTML to avoid the styling issue experienced with the earlier itinerary. The page uses internet-loaded photographs and Google Fonts, so the images/fonts require an internet connection. Some photography is evocative/illustrative rather than an exact photograph of each named stop.

## Editable items

- Hotel names and precise pick-up points when confirmed.
- Attractions, optional meals, service inclusions and fees.
- Order of activities on December 26 depending on Hoi An hotel location.
- Exact transfer/check-in timing on December 27.

## Notes

- The trip schedule is indicative and is not a booking confirmation.
- No guest form, analytics, contact collection or external backend is included.
- The built-in 'Save as PDF' button opens the browser print dialog.
